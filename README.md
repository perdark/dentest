# زُهى — نظام سجلات وحسابات العيادة (Zuha)

نظام محلّي لإدارة سجلات وحسابات عيادة أسنان، يحلّ محلّ الدفاتر الورقية. يعمل على جهاز العيادة
على `localhost` — بدون إنترنت أو سحابة. عربي، RTL، دينار عراقي، رمز دخول واحد مشترك.

## التشغيل لأول مرة
```bash
npm install
npm run db:setup     # ينشئ قاعدة البيانات + البيانات الأولية (الأطباء، أنواع العلاج)
npm run build
npm start            # ثم افتح http://localhost:3000
```
- **رمز الدخول الافتراضي: `1234`** — غيّره فوراً من صفحة **الإعدادات**.
- لا توجد أسعار افتراضية — سعر كل حالة يُكتب عند فتحها (الأسعار تختلف من مريض إلى آخر).
- نِسَب الأطباء تبدأ **فارغة (غير مؤكدة)** عمداً — تُدخَل من الإعدادات بعد تأكيدها مع العيادة.

### الشبكة والأمان
`npm start` يستمع على `127.0.0.1` فقط، أي أن النظام لا يُفتح إلا من جهاز العيادة نفسه — وهذا
هو المقصود. إذا احتجتَ فتحه لأجهزة أخرى على شبكة العيادة استخدم `npm run start:lan`، وغيّر رمز
الدخول إلى رمز أطول أولاً. يوجد قفل تلقائي بعد ٥ محاولات خاطئة.

### نسيتَ رمز الدخول؟
من جهاز العيادة:
```bash
npm run pin:reset            # يرجع الرمز إلى 1234
npm run pin:reset -- 4821    # أو رمز تختاره
```
يُلغي هذا كل الجلسات المفتوحة، ويتطلّب الوصول الفعلي إلى الجهاز.

## الشاشات
لوحة التحكم · **المواعيد (السجل الرئيسي)** · الدفتر اليومي · المرضى · الزراعة (الفهرس +
البطاقة) · التقويم · الأشعة · الديون · المصروفات · **الحركات النقدية** ·
الحصيلة الشهرية · **سجل التعديلات** · الدليل · الإعدادات.

## النسخ الاحتياطي — مهم
من **الإعدادات ← نسخ قاعدة البيانات الآن** — يحفظ نسخة في مجلد `backups/`.

> ⚠️ مجلد `backups/` موجود **على نفس القرص** مع قاعدة البيانات. إذا تعطّل الجهاز تضيع سجلات
> العيادة كلها. **انسخ الملف إلى فلاش USB أو قرص خارجي أسبوعياً على الأقل.**

```bash
# نسخة يدوية إلى فلاش
cp zuha.db /media/usb/zuha-$(date +%F).db
```
نسخة يومية من داخل النظام + نسخة خارجية أسبوعية.

## تصحيح خطأ في الإدخال
قيد دفعة أُدخل بالخطأ يُلغى من زرّ السلة بجانب القيد (في الدفتر اليومي أو بطاقة المريض).
**لا تستخدم «استرجاع» لتصحيح خطأ مطبعي** — الاسترجاع حدث مالي حقيقي يُخصم من حصة الطبيب.
كل إلغاء يبقى مسجّلاً في **سجل التعديلات**.

## الاختبار
```bash
npm run typecheck    # فحص الأنواع
npm test             # اختبارات طبقة المال (الدفعات، الحصص، سجل التعديلات)
npm run verify       # تحقّق شامل من منطق المال على قاعدة بيانات مؤقتة
npm run lint
```

## أرقام غير مؤكدة (Layer 2)
نِسَب الأطباء، صيغة احتساب المختبر، قاعدة الـ٥ مليون، ورواتب الموظفين — كلها **غير مؤكدة**
ومعلّمة في صفحة الإعدادات. عند تأكيدها من العيادة، تُعدَّل من الإعدادات بدون تغيير الكود.
الافتراضي الحالي: النسبة تُحسب على المبلغ المُحصَّل، وأجور المختبر مصروف عام للعيادة.

## التشغيل التلقائي عند الإقلاع (اختياري)
استخدم `pm2` أو وحدة `systemd`:
```bash
npm install -g pm2
npm run build
pm2 start "npm start" --name zuha
pm2 startup && pm2 save
```
