## Locked decisions
- **Labs:** EVERY doctor has his own lab (name editable, e.g. علي → «دوبرا»). Lab money = **standalone entries** on the doctor page (date, amount, note, optional patient). Each lab has **two branches: ثابت + متحرك** — every entry is tagged, both totals shown.
- **Lab money is TRACK-ONLY:** never touches clinic cash, never enters settlement payout. Shown on doctor pages + one info line in settlement. (Integrated option documented in OWNER-NOTES as a future switch.)
- **Access:** one shared PIN stays. No roles. Doctor pages open to anyone logged in; secretary edits everything.
- **Ortho: agreed total REMOVED COMPLETELY.** Ortho money = المقدمة (initial amount) + each session its own amount. No الإجمالي, no المتبقي anywhere in ortho UI. Ortho never appears in debts.
- **«تسجيل» removed everywhere** in visible copy (reworded: إضافة/حفظ/حجز…).
- **«المستحقات» → «الديون»** (patient balances). The word «مستحقات» is now reserved for DOCTOR dues.
- **قائمة الأسعار removed** (nav + page + prefills). Prices typed manually per case. `price_list` table stays dormant.
- **Treatment in daily entry = free text** with saved suggestions (find-or-create treatment type, bucket `normal`; non-normal names refused → protects D9).
- **Live math in every money form** (see cross-cutting item below).
